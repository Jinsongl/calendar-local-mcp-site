Privacy Policy

Effective date: 11 November 2026 · Last updated: 11 November 2026

This Privacy Policy describes how Calendar Local MCP (“the Application”) accesses, uses, stores, and shares Google user data. The Application is a personal-use Windows utility operated by its owner.

1. Data the Application accesses

When the owner authorizes the Application, it may access:

  • The list of Google calendars visible to the authorized Google account, to identify the calendar selected for an operation.
  • Calendar event information, including event titles, descriptions, locations, dates and times, attendees, and event identifiers, to the extent returned by the Google Calendar API and needed for the requested operation.

The OAuth permissions used are the Google Calendar events scope and the calendar-list read-only scope. The Application does not request Gmail, Google Drive, contacts, or unrelated Google account data.

2. How data is used

Google Calendar data is used only to perform actions initiated by the owner through the local MCP client, such as listing calendars, searching or reading events, creating events, updating events, and deleting events. The Application does not sell Google user data, use it for advertising, or use it to determine creditworthiness or for other unrelated purposes. Google user data is not used to train or improve generalized artificial intelligence or machine-learning models.

3. Storage and security

The Application is designed to run locally on the owner's Windows computer. OAuth client configuration and OAuth tokens are stored in the owner's local Windows user profile, in the Application's data directory. Calendar event content is not intentionally stored in a developer-operated cloud database or transmitted to the Application maintainer.

API traffic is sent to Google over HTTPS. The owner may configure a local network proxy on their computer to reach Google services. The Application maintainer does not control that proxy or its operator. The owner is responsible for protecting the Windows account, local files, backups, and any proxy service they choose to use.

4. Sharing and disclosure

The Application does not disclose Google Calendar data to the Application maintainer or other third parties. Data is transmitted to Google as necessary to make Google Calendar API requests and receive responses. If the owner creates an event with attendees, Google may process and deliver invitations or notifications according to the owner's event settings and Google's services.

5. Retention and deletion

OAuth credentials and tokens remain in the local data directory until the owner deletes them. Local backups may also contain copies and must be deleted separately. Calendar events remain in Google Calendar according to the owner's actions and Google's retention behavior; the Application does not independently retain a separate event archive.

The owner can stop future access by revoking the Application's access in their Google Account at Google Account third-party connections, then deleting the local OAuth token and any backups. Deleting a local token does not itself delete events already stored in Google Calendar. Events created by the Application must be deleted separately in Google Calendar or through an authorized calendar operation.

6. Children's privacy

The Application is a personal productivity utility and is not directed to children. It is not designed to collect personal information from children.

7. Changes to this policy

This policy may be updated if the Application's functionality or data practices change. The updated policy will be published at this URL with a revised effective date.
