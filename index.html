Calendar Local MCP

Calendar Local MCP is a personal Windows application that connects an MCP-compatible assistant running on the same computer to the owner's Google Calendar account.

What the application does

The application runs locally on the user's Windows computer. It exposes calendar tools to a locally running MCP client, such as Codex. Depending on the tool invoked, it can list calendars, find and read events, create events, update events, and delete events.

How Google data is used

The application requests access to the Google Calendar list and calendar events. Calendar information is used only to carry out the calendar operation explicitly requested by the user. The application does not sell Google user data, use it for advertising, or use it to build or train generalized AI or machine-learning models.

Privacy

OAuth credentials and tokens are stored in the local Windows user profile on the computer where the application runs. Calendar requests are sent to Google through the Google Calendar API. The application does not operate a developer-hosted backend and does not intentionally transmit calendar content to the application maintainer.

Read the Privacy Policy for details about access, use, storage, retention, and revocation.

Who this application is for

This is a personal-use utility for its owner. It is not a public calendar service, does not provide accounts to other users, and is not affiliated with or endorsed by Google or OpenAI.
